# 🚗 Car Price Prediction using Machine Learning

A Machine Learning-based web application that predicts the estimated price of a used car based on important car details such as car model, manufacturing year, kilometers driven, fuel type, transmission, and number of previous owners.

## 🧠 Machine Learning

This project uses **Supervised Machine Learning – Regression**.

### Algorithm
- Random Forest Regression

### Features
- Car Model
- Manufacturing Year
- Kilometers Driven
- Fuel Type
- Transmission
- Previous Owners

## 🛠️ Technologies Used

- Python
- Pandas
- Scikit-learn
- Flask
- HTML
- CSS
- Random Forest Regression
